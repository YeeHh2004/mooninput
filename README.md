# MoonInput

MoonBit-native structured input editing: patterns, decimal text, selection replacement and caret mapping. A reusable library with a browser adapter and runnable form examples.

Development starts with a pure, deterministic core. See [selection research](docs/SELECTION.md) and [behavior contract](docs/DESIGN.md).
